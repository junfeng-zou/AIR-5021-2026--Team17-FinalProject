# 基于 OpenVLA-7B 的机械臂倒水任务研究与实现

## 中期展示说明文档

## 一、项目概述

### 1.1 研究目标

本研究旨在基于视觉-语言-动作（VLA）模型，实现 DOBOT CR5/Nova 5 机械臂的倒水任务自动化。具体目标包括：

- **数据采集**：通过仿真环境和真机遥操作，采集机械臂执行倒水任务的演示数据
- **模型训练**：利用 OpenVLA-7B 预训练模型，结合 LoRA 微调技术，使模型学习倒水技能
- **部署推理**：将训练好的模型部署到仿真环境和真机，实现自主倒水

### 1.3 任务定义

**倒水任务**：`"pour water from bottle into cup"`

机械臂需要完成以下子步骤：
1. 移动到瓶子位置
2. 夹取瓶子
3. 移动到杯子上方
4. 倾斜瓶子倒出水球
5. 将瓶子放回原位

## 二、技术背景

### 2.1 OpenVLA-7B 模型

OpenVLA 是一个开源的视觉-语言-动作模型，基于 Llama-2-7B 语言模型构建，主要特点：

- **视觉编码器**：使用 SigLIP 视觉 transformer，将输入图像编码为视觉 token
- **语言模型**：基于 Llama-2-7B，进行指令微调
- **动作预测**：将 7 维连续动作离散化为 256 个 bin，预测动作 token

**动作离散化**：
- 7 维动作（dx, dy, dz, droll, dpitch, dyaw, gripper）
- 每个维度均匀划分为 256 个 bin
- 归一化到 [-1, 1] 范围

### 2.2 LoRA 微调技术

LoRA（Low-Rank Adaptation）是一种参数高效微调技术：

- **核心思想**：在预训练模型旁路添加低秩矩阵，不改变原始权重
- **参数量**：仅训练约 0.1% 的参数（相比全量微调）
- **优势**：单卡可训练，显存占用低，训练速度快

**本项目配置**：
| 参数 | 值 |
|------|-----|
| LoRA 秩 (r) | 64 |
| LoRA alpha | 128 |
| LoRA dropout | 0.05 |
| 目标模块 | `llm`（仅语言注意力）/ `all-linear`（视觉+语言） |

### 2.3 Isaac Lab 仿真环境

Isaac Lab 是 NVIDIA 提供的高性能机器人仿真平台：

- **物理引擎**：基于 PhysX，精确模拟刚体动力学
- **渲染引擎**：支持实时光线追踪渲染
- **传感器**：支持 RGB 相机、深度相机、IMU 等

#### 运动控制

| 输入 | 控制 | 说明 |
|------|------|------|
| 左摇杆 ↑↓ | EE 前后 (X) | 推杆向前 → +X |
| 左摇杆 ←→ | EE 左右 (Y) | 推杆向右 → +Y |

### 3.5 数据格式

每个 episode 保存为一个独立的 HDF5 文件。

```
episode_XXXX.hdf5
├── observations/
│   ├── images/
│   │   ├── rgb          (T, 224, 224, 3)   uint8
│   │   ├── depth        (T, 224, 224, 1)   float32
│   │   └── rgb_side     (T, 224, 224, 3)   uint8
│   └── state            (T, 20)            float32
├── actions               (T, 7)            float32
├── timestamps            (T,)              float64
└── attrs
    ├── num_steps, dt, task, image_size
    ├── model_target, action_dim, action_range, robot
```

**动作空间（7 维）**：

| 索引 | 名称 | 含义 | 范围 |
|------|------|------|------|
| 0 | `dx` | 末端 X 方向平移 | [-1, 1] |
| 1 | `dy` | 末端 Y 方向平移 | [-1, 1] |
| 2 | `dz` | 末端 Z 方向平移 | [-1, 1] |
| 3 | `droll` | 末端绕 X 轴旋转 | [-1, 1] |
| 4 | `dpitch` | 末端绕 Y 轴旋转 | [-1, 1] |
| 5 | `dyaw` | 末端绕 Z 轴旋转 | [-1, 1] |
| 6 | `gripper` | 夹爪状态 | +1=打开, -1=关闭 |

### 3.6 数据多样性机制

**位置随机化**：每次环境 reset 时，杯子和瓶子的位置会在预设范围内随机采样：

| 物体 | X 范围 (m) | Y 范围 (m) |
|------|-----------|-----------|
| 杯子 | [0.30, 0.55] | [-0.15, 0.15] |
| 瓶子 | [0.30, 0.55] | [-0.15, 0.25] |

**语言指令多样化**：每次录制时从 8 条语义等价指令中随机选择：
- "pour water from bottle into cup"
- "pick up the bottle and pour water into the cup"
- "fill the cup with water from the bottle"
- "grasp the bottle and pour its contents into the cup"
- ...等

### 3.7 采集建议

- **最少 50 个 episode**（能跑通训练流程）
- **推荐 200–500 个 episode**（获得较好泛化效果）
- **理想 500–1000 个 episode**（位置变化大时需要更多数据）
- 每个 episode 通常 50–200 步（5–20 秒 @10Hz）

### 4.3 训练参数

| 参数 | 默认值 | 说明 |

|-----|------|-----------|------------|------------|
| RTX 3090 | 24GB | 2 | 16 | 32 |

## 八、关键技术点

### 8.1 动作离散化

OpenVLA 将连续动作空间离散化为 256 个 bin：

```python
# 归一化
action_norm = (action - min) / (max - min) * 2 - 1  # [-1, 1]

# 离散化
action_bins = ((action_norm + 1) / 2 * 255).astype(int)  # [0, 255]

# 预测时还原
action_pred = action_bins / 255 * 2 - 1  # [-1, 1]
```

### 8.2 动作反归一化

推理时使用训练集的统计信息还原真实动作：

```python
action_denorm = action_pred * actions_std + actions_mean
```

### 8.3 Prompt 格式

OpenVLA 使用 VicunaV1.5 格式的 prompt：

```
<image>
What action should the robot take to {task}?
```

### 8.4 相机标定

Isaac Lab 的 CameraCfg 使用世界坐标系约定（+X 前，+Z 上），与 OpenGL 约定（-Z 前，+Y 上）不同，采集时已做适配处理。
